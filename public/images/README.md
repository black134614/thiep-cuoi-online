# Thư mục ảnh

Đặt tài nguyên ảnh tại đây. Các đường dẫn được tham chiếu trong `src/data/wedding.ts`.

- `groom.jpg`, `bride.jpg` — ảnh chân dung cô dâu/chú rể
- `gallery/01.jpg ... 06.jpg` — album ảnh cưới (agent-gallery)
- `qr-groom.png`, `qr-bride.png` — mã QR phong bao (agent-gift)

> Khi chưa có ảnh thật, có thể dùng ảnh placeholder để dev giao diện.
